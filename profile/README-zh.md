# Hi there 👋

🧑‍💻 **简介** — AuthBoot 是一个跨平台的开发起步套件，面向独立开发者、Indie Hacker 和小团队。我们提供可复用的基础设施，涵盖身份认证、用户管理与应用开发，帮助开发者跳过重复的搭建工作，专注于打磨产品本身。

🚀 **我们的使命** — 让做产品更简单。少花时间在基础设施上，多花时间在想法上。

📚 **实用资源** — [官网](https://authboot.com)、[GitHub](https://github.com/authboot)

🧰 **我们正在做的事** — 身份认证与用户管理、后端基础设施、跨平台开发、开发者工具。

🌱 **我们的理念** — 更少配置，更多创造。

🤝 **适合谁用** — 独立开发者、AI 构建者、Indie Hacker，以及拥抱 Vibe Coding 的团队。
